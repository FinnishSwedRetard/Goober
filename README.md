# Browser Arcade

A small collection of no-install games, with a retro-style game picker. Open `index.html` to browse the games, then click **Play now**. Each game is a single HTML file with all its code and graphics included. No Python, add-ons, internet connection, or setup are needed.

## Games

- **Comet Courier** (`comet-courier.html`): Dodge space rocks, collect stardust, and try to beat your best score. Steer with the left/right arrow keys or **A**/**D**; drag on a touchscreen.
- **Mini Tetris** (`tetris.html`): Stack falling blocks and clear lines. Move with **←/→**, rotate with **↑**, soft drop with **↓**, hard drop with **Space**, and pause with **P**. Touch controls are included.
- **Snack Snake** (`snake.html`): Eat snacks, grow longer, and avoid the walls and your tail. Steer with the arrow keys or **W/A/S/D**; press **Space** to pause. Touch controls are included.

## Play and share

Download the whole repository with **Code → Download ZIP** and extract it to a folder, or copy its HTML files together onto a USB stick. Open `index.html` to browse the game collection, or open a game's HTML file directly. Share the folder or ZIP with friends to play offline.

Windows does not automatically launch files from USB drives. To start the arcade, open `index.html` manually after plugging in the USB; an HTML file or script on the drive cannot make Windows auto-launch it when plugged in. If a managed device blocks local HTML files, use a school-approved way to play rather than bypassing its protections.
