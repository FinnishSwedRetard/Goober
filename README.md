# Browser Arcade

A small collection of no-install games, with a retro-style game picker and the owner's original character as its mascot. Open `index.html` to browse the games, then click **Play now**. The games need no Python, add-ons, or internet connection.

## Games

- **Comet Courier** (`comet-courier.html`): Dodge space rocks, collect stardust, and try to beat your best score. Steer with the left/right arrow keys or **A**/**D**; drag on a touchscreen.
- **Mini Tetris** (`tetris.html`): Stack falling blocks and clear lines. Move with **←/→**, rotate with **↑**, soft drop with **↓**, hard drop with **Space**, and pause with **P**. Touch controls are included.
- **Snack Snake** (`snake.html`): Eat snacks, grow longer, and avoid the walls and your tail. Steer with the arrow keys or **W/A/S/D**; press **Space** to pause. Touch controls are included.
- **Parking Lot Drift** (`drift.html`): Slide a little red car around the parking lot and build a drift combo in a 90-second run. Use **W/A/S/D** or the arrow keys; **Space** is the handbrake and **P** pauses. Touch controls are included.

## Play and share

Download the whole repository with **Code → Download ZIP** and extract it to a folder, or copy the files together onto a USB stick. Open `index.html` to browse the game collection, or open a game's HTML file directly. Keep the `assets` folder alongside the HTML files for the arcade mascot and Parking Lot Drift's car sprites. Share the folder or ZIP with friends to play offline.

The car sprites are from [Desktop-Drift](https://github.com/FinnishSwedRetard/Desktop-Drift/tree/main/Car%20Game/Assets/Car) and are bundled locally so Drift works offline.

Windows does not automatically launch files from USB drives. To start the arcade, open `index.html` manually after plugging in the USB; an HTML file or script on the drive cannot make Windows auto-launch it when plugged in. If a managed device blocks local HTML files, use a school-approved way to play rather than bypassing its protections.
